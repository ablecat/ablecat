## 🔬 Research Projects

### ReliableGS: Geometry Reliability Regularized Gaussian Splatting

**First Author · Computer Graphics International (CGI 2026, CCF-C)**

A framework for improving transparent surface reconstruction with reliable geometric supervision.

Key ideas:

- Pixel-wise geometry reliability estimation
- Adaptive loss modulation
- Reliability-guided Gaussian pruning

Achievements:

- Improved geometric consistency for transparent objects
- Reduced redundant Gaussian primitives

---

### GlossyDeform-GS: Editable Gaussian Representation for Glossy Objects

**First Author · CAD (Under Review)**

A framework for editable Gaussian representations with view-dependent appearance.

Key ideas:

- BRDF-aware appearance decomposition
- Deformation-aware Gaussian transformation
- Normal and tangent consistency preservation

Supports:

- Geometry editing
- Material-aware manipulation
- Relighting of glossy objects

---

### Transparent Object Reconstruction with Efficient Environment Modeling

**Patent Applicant (Second Inventor)**

Focused on lightweight environment representation for physically realistic transparent object reconstruction.

Techniques:

- Neural environment representation
- Voxel importance pruning
- Vector quantization compression
